# Anza-Borrego State Park Challenge

A turn-based web board game for 2 to 8 players, played from phones in the same room or remotely.

- [Build plan](docs/PLAN.md)
- [Rules notes](docs/RULES-NOTES.md)
- [Audio research](docs/AUDIO-RESEARCH.md)
- [Milestone 1 prototype: run locally, MAMP, Network Solutions deploy](docs/PROTOTYPE.md)

The game lives in `desertranger/` (plain PHP + MySQL + vanilla JS). Images, audio and
fonts are not in git: unzip `desertranger-assets-for-mac.zip` at the repo root.
